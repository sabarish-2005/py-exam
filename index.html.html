How to run these programs (Windows, one-time setup)
  1. Open IDLE. Start menu, type IDLE, open it. Choose File > New File, paste the code, press Ctrl+S and save it as ex11.py (any name ending .py, any folder).
  2. Run it. Press F5 in IDLE. The output appears in the Shell window. Programs with a menu or input() ask you to type in that Shell window.
  3. Install libraries once for Ex6 to Ex12 (they use numpy, matplotlib, pandas). Open Command Prompt (not IDLE), type this and press Enter:
    pip install numpy matplotlib pandas
    If it says pip is not recognized, use this instead:
    python -m pip install numpy matplotlib pandas
  4. Check that they installed. In Command Prompt:
    python -c "import numpy, matplotlib, pandas; print('All OK')"
  5. Run from Command Prompt instead (optional). cd to the folder with your file, then type python ex11.py.

Error ModuleNotFoundError: No module named 'numpy' (or matplotlib, pandas) means step 3 is not done yet. Installing needs internet, so do it before the exam. Ex1 to Ex5 need nothing to install.
